# Nitin Goyal — Portfolio

🚀 Personal portfolio website showcasing my work, experience, and projects as a Software Engineer.

🔗 **Live Website:**  
👉 https://nitin-goyal-portfolio.vercel.app

---

## ✨ Overview

This portfolio highlights:
- My experience as a **Software Engineering Intern at Google**
- Selected projects across **Backend, AI/ML, and Android**
- Skills and technical focus areas
- Clean, minimal, and responsive UI built with modern tooling

The website is designed to be **fast, minimal, and engineer-focused**, avoiding unnecessary complexity.

---

## 🛠 Tech Stack

- **Frontend:** React
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Deployment:** Vercel

---

## 📂 Features

- Fully responsive design (mobile-first)
- Clean hero section with an engineer-style JSON career summary
- Projects with GitHub and Drive links
- Experience section with measurable impact
- Minimal contact section with social links
- Optimized performance using Vite + React

---

## 🚀 Running Locally

Clone the repository:

```bash
git clone https://github.com/nitingoyal123/Portfolio
cd Portfolio

npm install
npm run dev

```
Website will be available at [localhost](http://localhost:5173)
